## 用户管理

### GET /api/admin/users - 用户列表

**Query参数:** keyword, page, size

### PUT /api/admin/users/:id - 更新用户

**请求体:**

```json
{
  "username": "string",
  "email": "string",
  "nickname": "string",
  "status": 1,
  "role": 0,
  "max_apps": -1,
  "max_users": -1,
  "max_card_types": -1,
  "max_cards": -1
}
```

**说明:** 不能修改自己的角色，不能禁用自己。

### DELETE /api/admin/users/:id - 删除用户

级联删除用户所有关联数据。不能删除自己。

### POST /api/admin/users/:id/recharge - 用户余额充值

**请求体:**

```json
{
  "amount": 100.00,
  "remark": "管理员充值"
}
```

**响应:**

```json
{ "code": 0, "message": "充值成功", "data": { "balance": 200.00 } }
```
