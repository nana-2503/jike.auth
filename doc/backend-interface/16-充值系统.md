# 充值系统接口

平台余额充值，对接易支付。

---

## 公开接口

### GET /api/recharge/packages - 获取充值套餐

见 [01-公开接口.md](./01-公开接口.md)

### POST /api/recharge/notify - 易支付异步回调

易支付服务器回调，自动处理订单状态和余额更新。支持 GET 和 POST。

### GET /api/recharge/return - 易支付同步回调

重定向到前端结果页 `/recharge/result?order_no=xxx`

---

## 用户接口（需登录）

### POST /api/user/recharge/order - 创建充值订单

**请求体:**

```json
{
  "package_id": 1,
  "pay_type": "alipay"  // alipay 或 wxpay
}
```

**响应:**

```json
{
  "code": 0,
  "data": {
    "order_no": "R16409520001",
    "pay_url": "https://pay.example.com/submit.php?..."
  }
}
```

**说明:** 前端跳转到 pay_url 完成支付。

### GET /api/user/recharge/order - 查询订单状态

**Query参数:** order_no

**响应:**

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "order_no": "R16409520001",
    "user_id": 1,
    "package_id": 1,
    "amount": 10.00,
    "balance_amount": 10.00,
    "pay_type": "alipay",
    "status": 0,
    "trade_no": "",
    "paid_at": null,
    "created_at": "..."
  }
}
```

**status:** 0=待支付 1=已支付

### GET /api/user/recharge/orders - 充值记录

**Query参数:** page, size
