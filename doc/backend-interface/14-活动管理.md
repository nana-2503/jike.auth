# 活动管理接口

需要登录。管理抽奖/定时开奖活动。

---

## GET /api/user/activities - 活动列表

**Query参数:** page, size

---

## GET /api/user/activities/:id - 活动详情

---

## POST /api/user/activities - 创建活动

**请求体:**

```json
{
  "name": "活动名称",
  "type": 1,
  "status": 1,
  "start_at": "2026-01-01T00:00:00Z",
  "end_at": "2026-12-31T23:59:59Z"
}
```

---

## PUT /api/user/activities/:id - 更新活动

---

## DELETE /api/user/activities/:id - 删除活动

---

## POST /api/user/activities/:id/prizes - 保存活动奖品

**请求体:** 奖品列表数组

---

## GET /api/user/activities/:id/records - 活动记录列表

---

## POST /api/user/activities/:id/draw - 手动开奖

---

## 活动用户管理

### GET /api/user/activity-users - 活动用户列表

### DELETE /api/user/activity-users/:id - 删除活动用户

### PUT /api/user/activity-users/:id/password - 重置活动用户密码

### GET /api/user/activity-users/:id/records - 活动用户记录
