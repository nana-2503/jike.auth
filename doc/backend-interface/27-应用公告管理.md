# 应用公告管理接口

需要登录。管理应用级别的公告（区别于平台公告）。

---

## GET /api/user/app-announcements - 应用公告列表

**Query参数:** page, size, app_id

---

## POST /api/user/app-announcements - 创建应用公告

**请求体:**

```json
{
  "app_id": 1,
  "title": "公告标题",
  "content": "公告内容",
  "status": 1,
  "sort": 0
}
```

**字段说明:**

| 字段 | 说明 |
|------|------|
| status | 0:禁用 1:启用 |
| sort | 排序号，越大越靠前 |

---

## PUT /api/user/app-announcements/:id - 更新应用公告

---

## DELETE /api/user/app-announcements/:id - 删除应用公告
