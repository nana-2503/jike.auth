# 社交登录接口

支持 QQ、GitHub、微信等第三方登录。

---

## 公开接口

### GET /api/config/social-login - 获取社交登录状态

返回各平台是否启用。

### GET /api/auth/social/url - 获取社交登录URL

**Query参数:** type（qq/github/wechat）

前端跳转到返回的URL进行第三方授权。

### GET /api/auth/social/callback - 社交登录回调

第三方平台回调地址，自动处理登录/注册逻辑。

### POST /api/auth/social/bind - 绑定社交账号

已有账号绑定第三方账号。

### POST /api/auth/social/register-bind - 注册并绑定

新用户通过第三方账号注册并绑定。

---

## 用户接口（需登录）

### GET /api/user/social-accounts - 获取已绑定的社交账号

### DELETE /api/user/social-accounts/:type - 解绑社交账号

**路径参数:** type - 平台类型（qq/github/wechat）
