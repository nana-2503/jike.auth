# 授权证书管理接口

需要登录。管理应用的授权证书。

---

## POST /api/user/licenses/generate - 生成证书码

生成一个新的证书码（含混淆密钥）。

---

## POST /api/user/licenses/encrypt - 加密预览

**请求体:**

```json
{
  "certificate": "证书码",
  "content": "要加密的内容"
}
```

**响应:** 返回加密后的内容。

---

## POST /api/user/licenses/decrypt - 解密内容

**请求体:**

```json
{
  "certificate": "证书码",
  "encrypted_data": "加密内容"
}
```

---

## GET /api/user/licenses - 证书列表

**Query参数:** page, size

**响应数据字段:**

| 字段 | 说明 |
|------|------|
| name | 证书名称 |
| certificate | 证书码 |
| encrypted_data | 加密后的附加内容 |
| max_use | 最大使用次数，0=不限 |
| used_count | 已使用次数 |
| bind_feature | 绑定特征码（空=不绑定） |
| status | 1:启用 0:禁用 |
| expire_at | 过期时间 |

---

## GET /api/user/licenses/:id - 证书详情

## POST /api/user/licenses - 创建证书

**请求体:**

```json
{
  "app_id": 1,
  "name": "证书名称",
  "certificate": "证书码",
  "encrypted_data": "加密内容",
  "max_use": 0,
  "bind_feature": "",
  "remark": "",
  "status": 1,
  "expire_at": "2026-12-31 23:59:59"
}
```

## PUT /api/user/licenses/:id - 更新证书

## DELETE /api/user/licenses/:id - 删除证书
