# 公开接口

无需登录即可访问的接口。

---

## POST /api/auth/register - 用户注册

注册平台账号。

**请求体:**

```json
{
  "username": "string",    // 必填，3-20个字符
  "email": "string",       // 必填，有效邮箱
  "password": "string",    // 必填，至少6个字符
  "email_code": "string",  // 邮箱验证码（如果注册配置要求）
  "captcha_id": "string",  // 图形验证码ID（如果注册配置要求）
  "captcha": "string"      // 图形验证码值（如果注册配置要求）
}
```

**成功响应:**

```json
{ "code": 0, "message": "注册成功" }
```

**失败响应:**

```json
{ "code": 1, "message": "用户名已存在" }
{ "code": 1, "message": "邮箱已被注册" }
{ "code": 1, "message": "注册过于频繁，请稍后再试" }
{ "code": 1, "message": "请输入图形验证码", "need_captcha": true }
```

**说明:**
- 同IP每小时注册次数受 `reg_rate_limit` 限制（默认5次）
- 注册后自动获得默认配额（max_apps, max_users, max_card_types, max_cards）

## POST /api/auth/login - 用户登录

**请求体:**

```json
{
  "username": "string",    // 必填，支持用户名或邮箱
  "password": "string",    // 必填
  "captcha_id": "string",  // 图形验证码ID（失败次数达到阈值后需要）
  "captcha": "string"      // 图形验证码值
}
```

**成功响应:**

```json
{
  "code": 0,
  "data": {
    "token": "jwt_token_string",
    "user": {
      "id": 1,
      "username": "test",
      "email": "test@example.com",
      "nickname": "test",
      "avatar": "/uploads/avatars/xxx.jpg",
      "role": 0,
      "status": 1,
      "balance": 100.00,
      "max_apps": -1,
      "max_users": -1,
      "max_card_types": -1,
      "max_cards": -1,
      "activity_code": "abc12345",
      "created_at": "2026-01-01T00:00:00Z"
    }
  }
}
```

**失败响应:**

```json
{ "code": 1, "message": "用户名或密码错误", "need_captcha": false }
{ "code": 1, "message": "账号已被禁用" }
{ "code": 1, "message": "登录失败次数过多，请30分钟后再试", "locked": true }
```

**说明:**
- 登录失败达到 `captcha_after_fails` 次后需要验证码
- 失败达到 `max_login_fails` 次后锁定 `lock_duration` 分钟

## GET /api/auth/login-status - 获取登录状态

检查当前IP是否需要验证码或已被锁定。

**响应:**

```json
{
  "code": 0,
  "data": {
    "need_captcha": false,
    "locked": false,
    "fail_count": 0
  }
}
```

## POST /api/auth/send-code - 发送注册验证码

**请求体:**

```json
{ "email": "user@example.com" }
```

**响应:**

```json
{ "code": 0, "message": "验证码已发送" }
```

**说明:** 1分钟内只能发送一次，验证码5分钟有效。

## POST /api/auth/reset-password - 重置密码

**请求体:**

```json
{
  "email": "user@example.com",
  "code": "123456",
  "new_password": "newpass123"  // 至少6位
}
```

**响应:**

```json
{ "code": 0, "message": "密码重置成功" }
```

**说明:** 重置密码后 token_version 递增，旧 token 失效。
