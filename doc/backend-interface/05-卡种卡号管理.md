# 卡种卡号管理接口

需要登录。

---

## 卡种管理

### GET /api/user/cardtypes - 卡种列表

**Query参数:**

| 参数 | 类型 | 说明 |
|------|------|------|
| app_id | int | 按应用筛选 |
| page | int | 页码 |
| size | int | 每页数量 |

**响应数据字段说明:**

| 字段 | 说明 |
|------|------|
| category | 1:充值卡 2:登录卡 |
| prefix | 卡号前缀 |
| points | 充值点数 |
| rebate_points | 消费返利积分，充值成功后固定发放给直接上级，0=不返利 |
| duration | 充值时长（分钟），0=不充值，-1=永久 |
| gen_rule | 制卡规则 1:小写 2:大写 3:大小写 4:小写+数字 5:大写+数字 6:大小写+数字 |
| max_use | 可充值次数 |
| max_user_use | 每用户可充值次数 |
| channels | 通道数量 |
| features | 特征数量 |
| unbind_* | 解绑次数限制，-1=无限 |
| card_length | 卡号长度（最小12） |
| withdraw_price | 提卡单价 |

### GET /api/user/cardtypes/:id - 卡种详情

### POST /api/user/cardtypes - 创建卡种

**请求体:**

```json
{
  "app_id": 1,            // 必填
  "name": "月卡",          // 必填
  "category": 1,           // 1:充值卡 2:登录卡
  "prefix": "YK",
  "points": 0,
  "rebate_points": 10,
  "duration": 43200,       // 30天=43200分钟
  "gen_rule": 6,
  "max_use": 1,
  "max_user_use": 1,
  "channels": 1,
  "features": 1,
  "unbind_day": -1,
  "unbind_week": -1,
  "unbind_month": -1,
  "unbind_halfy": -1,
  "unbind_year": -1,
  "unbind_total": -1,
  "card_length": 16,
  "extra_data": "",
  "remark": "",
  "withdraw_price": 0
}
```

**说明:** 受 max_card_types 配额限制。

### PUT /api/user/cardtypes/:id - 更新卡种

**请求体:** 所有字段可选

### DELETE /api/user/cardtypes/:id - 删除卡种

## 卡号管理

### POST /api/user/cards/generate - 生成卡号

**请求体:**

```json
{
  "card_type_id": 1,   // 必填
  "count": 100,         // 必填，1-1000
  "remark": "备注"
}
```

**响应:**

```json
{
  "code": 0,
  "data": {
    "batch_no": "20260101120000",
    "count": 100,
    "cards": ["YKabc123...", "YKdef456..."]
  }
}
```

**说明:** 受 max_cards 配额限制。

### GET /api/user/cards - 卡号列表

**Query参数:**

| 参数 | 类型 | 说明 |
|------|------|------|
| app_id | int | 按应用筛选 |
| card_type_id | int | 按卡种筛选 |
| batch_no | string | 按批次筛选 |
| status | int | 按状态筛选（1:未使用 2:已使用 3:已禁用） |
| keyword | string | 搜索卡号 |
| page | int | 页码 |
| size | int | 每页数量 |

### PUT /api/user/cards/:id/status - 更新卡号状态

**请求体:**

```json
{ "status": 3 }  // 1:未使用 2:已使用 3:已禁用
```

### DELETE /api/user/cards/:id - 删除卡号

### GET /api/user/cards/:id/usage - 获取卡号使用记录

**响应:**

```json
{
  "code": 0,
  "data": {
    "card_no": "YKabc123...",
    "records": [
      {
        "id": 1,
        "card_id": 1,
        "app_user_id": 1,
        "username": "user1",
        "action": "recharge",
        "ip": "127.0.0.1",
        "feature": "...",
        "created_at": "..."
      }
    ]
  }
}
```

### GET /api/user/cards/batches - 批次列表

**Query参数:** app_id（必填）

**响应:**

```json
{
  "code": 0,
  "data": [
    { "batch_no": "20260101120000", "count": 100, "created_at": "..." }
  ]
}
```

### POST /api/user/cards/batch-delete - 按批次删除

**请求体:**

```json
{
  "app_id": 1,
  "batch_no": "20260101120000"
}
```

### GET /api/user/cards/export - 导出批次卡号

**Query参数:** app_id, batch_no

**响应:** 返回卡号数组

### GET /api/user/cards/export-excel - 导出卡号为CSV

**Query参数:** app_id, card_type_id, batch_no, status

**响应:** CSV文件下载（UTF-8 BOM），最多10000条

### POST /api/user/cards/batch-delete-ids - 按ID批量删除

**请求体:**

```json
{ "ids": [1, 2, 3] }
```

### POST /api/user/cards/batch-status - 批量更新状态

**请求体:**

```json
{
  "ids": [1, 2, 3],
  "status": 3
}
```
