# 签到系统接口

需要登录。

---

## GET /api/user/checkin/status - 获取签到状态

**响应:**

```json
{
  "code": 0,
  "data": {
    "checked_in": false,
    "streak": 5,
    "total": 30
  }
}
```

---

## POST /api/user/checkin - 执行签到

**响应:**

```json
{
  "code": 0,
  "message": "签到成功",
  "data": {
    "reward": 10,
    "streak": 6,
    "streak_reward": 0
  }
}
```

---

## GET /api/user/checkin/logs - 签到日志

**Query参数:** page, size

---

## GET /api/user/checkin/month-logs - 月度签到日志

返回当月每天的签到记录，用于日历展示。
