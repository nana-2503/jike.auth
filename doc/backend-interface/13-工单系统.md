# 工单系统接口

需要登录。

---

## GET /api/user/tickets - 工单列表

**Query参数:** page, size

---

## POST /api/user/tickets - 创建工单

**请求体:**

```json
{
  "title": "工单标题",
  "content": "工单内容",
  "category": "bug"
}
```

---

## GET /api/user/tickets/:id - 工单详情

---

## GET /api/user/tickets/:id/messages - 工单消息列表

---

## POST /api/user/tickets/:id/messages - 发送工单消息

**请求体:**

```json
{ "content": "消息内容" }
```

---

## POST /api/user/tickets/:id/close - 关闭工单
