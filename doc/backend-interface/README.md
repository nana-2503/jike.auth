# 后端接口文档

本文档详细描述了 jike-auth 后端所有 API 接口，方便前端开发对接。

## 基础信息

- 基础路径: `/api`
- 认证方式: JWT Token，通过 `Authorization: Bearer <token>` 请求头传递
- 响应格式: JSON
- 通用响应结构:

```json
{
  "code": 0,       // 0=成功, 1=失败
  "message": "...", // 提示信息
  "data": {}       // 数据（可选）
}
```

## 认证说明

### 三种认证级别

1. **公开接口** - 无需任何认证
2. **用户接口** (`/api/user/*`) - 需要 JWT Token（`Authorization: Bearer <token>`）
3. **管理员接口** (`/api/admin/*`) - 需要 JWT Token + 管理员角色（role=1）
4. **代理接口** (`/api/agent/*`) - 需要代理 JWT Token

### JWT Token 获取

通过 `POST /api/auth/login` 登录成功后返回 token。

## 分页参数

大部分列表接口支持分页，通用参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| page | int | 1 | 页码 |
| size | int | 10 | 每页数量 |

分页响应格式：

```json
{
  "code": 0,
  "data": {
    "list": [],
    "total": 100
  }
}
```
