# 网盘管理接口（CloudPan）

需要登录。代理访问 CloudPan 网盘服务。

---

## GET /api/user/jike-auth/user - 获取网盘用户信息

---

## GET /api/user/jike-auth/buckets - 获取存储桶列表

---

## GET /api/user/jike-auth/files - 文件列表

**Query参数:** bucket, path, page, size 等

---

## GET /api/user/jike-auth/files/search - 搜索文件

**Query参数:** keyword

---

## POST /api/user/jike-auth/files/folder - 创建文件夹

**请求体:**

```json
{
  "bucket": "bucket_name",
  "path": "/folder/name"
}
```

---

## POST /api/user/jike-auth/files/upload - 上传文件

**请求:** `multipart/form-data`

---

## POST /api/user/jike-auth/files/batch-delete - 批量删除文件

**请求体:**

```json
{ "ids": [1, 2, 3] }
```

---

## GET /api/user/jike-auth/files/:id - 获取文件信息

---

## DELETE /api/user/jike-auth/files/:id - 删除文件

---

## GET /api/user/jike-auth/files/:id/direct-link - 获取直链

---

## GET /api/user/jike-auth/files/:id/download - 下载文件

---

## PUT /api/user/jike-auth/files/:id/rename - 重命名文件

**请求体:**

```json
{ "name": "新文件名" }
```

---

## PUT /api/user/jike-auth/files/:id/move - 移动文件

**请求体:**

```json
{ "target_path": "/new/path" }
```

---

## POST /api/user/jike-auth/files/:id/copy - 复制文件

---

## GET /api/user/jike-auth/files/:id/content - 获取文件内容

用于文本文件在线编辑。

---

## PUT /api/user/jike-auth/files/:id/content - 更新文件内容

**请求体:**

```json
{ "content": "文件内容" }
```

---

## 分享管理

### GET /api/user/jike-auth/shares - 分享列表

### POST /api/user/jike-auth/shares - 创建分享

### DELETE /api/user/jike-auth/shares/:id - 删除分享

---

## 回收站

### GET /api/user/jike-auth/trash - 回收站列表

### DELETE /api/user/jike-auth/trash - 清空回收站

### POST /api/user/jike-auth/trash/:id/restore - 恢复文件
