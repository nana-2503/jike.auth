# 在线管理接口

需要登录。管理在线会话。

---

## GET /api/user/online - 在线会话列表

**Query参数:**

| 参数 | 类型 | 说明 |
|------|------|------|
| app_id | int | 按应用筛选 |
| app_user_id | int | 按用户筛选 |
| keyword | string | 搜索（用户名/IP/Token） |
| page | int | 页码 |
| size | int | 每页数量 |

**响应数据字段:**

| 字段 | 说明 |
|------|------|
| token | 会话令牌 |
| version | 登录版本 |
| client_id | 客户端ID |
| client_os | 客户端系统 |
| client_ip | 客户端IP |
| feature | 特征信息 |
| login_at | 登录时间 |
| heartbeat_at | 最后心跳时间 |
| expire_at | 用户到期时间 |
| points | 点数余额 |

---

## GET /api/user/online/stats - 在线统计

**Query参数:** app_id（可选）

**响应:**

```json
{ "code": 0, "data": { "online_count": 20 } }
```

---

## GET /api/user/online/chart - 最近7天在线统计图表

**响应:**

```json
{
  "code": 0,
  "data": [
    {
      "date": "03-25",
      "login_users": 50,
      "online_users": 30,
      "online_devices": 35
    }
  ]
}
```

---

## DELETE /api/user/online/:id - 踢下线（单个会话）

---

## POST /api/user/online/kick-user - 踢下线（按用户）

**请求体:**

```json
{
  "app_id": 1,
  "app_user_id": 1
}
```

**响应:**

```json
{ "code": 0, "message": "已踢下线", "data": { "count": 2 } }
```
