# 应用管理接口

需要登录。管理用户创建的软件应用。

---

## GET /api/user/apps - 应用列表

**Query参数:**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| page | int | 1 | 页码 |
| size | int | 10 | 每页数量 |

**响应:**

```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 1,
        "user_id": 1,
        "app_name": "我的应用",
        "app_key": "32位hex字符串",
        "app_code": "2601-AB123456",
        "app_secret": "32位hex字符串",
        "description": "应用描述",
        "login_mode": 1,
        "billing_mode": 1,
        "heartbeat": 60,
        "crypto_mode": "aes-256-cbc",
        "sign_algo": "",
        "server_sign_algo": "",
        "bind_device": 0,
        "channel_mode": 1,
        "login_kick": 0,
        "reg_mode": 1,
        "reg_limit": 1,
        "reg_channels": 1,
        "reg_features": 1,
        "reg_duration": 0,
        "reg_points": 0,
        "trial_duration": 0,
        "trial_points": 0,
        "trial_limit": 0,
        "maintenance": 0,
        "status": 1,
        "created_at": "2026-01-01T00:00:00Z"
      }
    ],
    "total": 1
  }
}
```

**字段说明:**

| 字段 | 说明 |
|------|------|
| login_mode | 1:账号登录 2:卡密登录 3:两者都支持 |
| billing_mode | 1:完全免费 2:计时收费 3:计点收费 |
| heartbeat | 心跳周期（秒），最小10 |
| bind_device | 0:不绑定设备 1:绑定设备特征 |
| channel_mode | 1:单绑定通道 2:账户总通道 |
| login_kick | 0:通道满拒绝登录 1:踢掉最早会话 |
| reg_mode | 1:关闭注册 2:开放注册 3:需充值卡注册 4:限制次数注册 |
| reg_limit | 特征限制注册次数（reg_mode=4时有效） |
| maintenance | 0:正常 1:维护模式（禁止登录并踢下线） |

---

## POST /api/user/apps - 创建应用

**请求体:**

```json
{
  "app_name": "应用名称",       // 必填
  "description": "应用描述",
  "login_mode": 1,              // 1-3
  "billing_mode": 1,            // 1-3
  "heartbeat": 60,              // 最小10
  "crypto_mode": "aes-256-cbc",
  "app_secret": "",             // 留空自动生成
  "sign_algo": "",
  "server_sign_algo": "",
  "bind_device": 0,
  "channel_mode": 1,
  "login_kick": 0,
  "reg_mode": 1,
  "reg_limit": 1,
  "reg_channels": 1,
  "reg_features": 1,
  "reg_duration": 0,
  "reg_points": 0,
  "trial_duration": 0,
  "trial_points": 0,
  "trial_limit": 0
}
```

**响应:** 返回创建的应用对象（含自动生成的 app_key, app_code, app_secret）

**说明:** 受 max_apps 配额限制。

---

## PUT /api/user/apps/:id - 更新应用

**路径参数:** id - 应用ID

**请求体:** 同创建，所有字段可选，额外支持:

```json
{
  "maintenance": 1  // 开启维护模式时会踢掉所有在线会话
}
```

---

## DELETE /api/user/apps/:id - 删除应用

**路径参数:** id - 应用ID

**说明:** 级联删除所有关联数据（用户、卡号、卡种、版本、在线会话、代理、数据池、授权证书）。

---

## POST /api/user/apps/:id/reset-secret - 重置应用密钥

**路径参数:** id - 应用ID

**响应:**

```json
{
  "code": 0,
  "data": { "app_secret": "新的32位hex密钥" }
}
```
