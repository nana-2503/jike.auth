# 推广返利接口

需要登录。管理推广返利系统。

说明：返利奖励统一累积到软件用户的 `rebate_points`，可直接用于积分商城兑换。注册返利由推广配置里的 `reg_reward` 控制；消费返利由每个卡种的 `rebate_points` 控制，充值成功后固定发放给直接上级。
