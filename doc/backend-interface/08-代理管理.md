# 代理管理接口

需要登录。管理应用下的代理账号。

---

## GET /api/user/agents - 代理列表

**Query参数:** app_id, keyword, page, size

---

## GET /api/user/agents/:id - 代理详情

---

## POST /api/user/agents - 创建代理

**请求体:**

```json
{
  "app_id": 1,
  "username": "agent1",
  "password": "123456",
  "nickname": "代理昵称",
  "balance": 100.00,
  "qq": "",
  "phone": "",
  "remark": ""
}
```

---

## PUT /api/user/agents/:id - 更新代理

**请求体:** 所有字段可选

```json
{
  "password": "新密码",
  "nickname": "新昵称",
  "balance": 200.00,
  "qq": "",
  "phone": "",
  "status": 1,
  "remark": ""
}
```

---

## DELETE /api/user/agents/:id - 删除代理

同时删除代理的卡种权限。

---

## POST /api/user/agents/:id/recharge - 代理充值余额

**请求体:**

```json
{ "amount": 100.00 }
```

**响应:**

```json
{ "code": 0, "message": "充值成功", "data": { "balance": 200.00 } }
```

---

## GET /api/user/agents/:id/cardtypes - 获取代理卡种权限

**响应:**

```json
{
  "code": 0,
  "data": [
    {
      "id": 1,
      "agent_id": 1,
      "card_type_id": 1,
      "price": 5.00,
      "card_type": { "id": 1, "name": "月卡", "..." }
    }
  ]
}
```

---

## POST /api/user/agents/:id/cardtypes - 设置代理卡种权限

**请求体:**

```json
{
  "card_types": [
    { "card_type_id": 1, "price": 5.00 },
    { "card_type_id": 2, "price": 10.00 }
  ]
}
```

**说明:** 全量替换，先删除旧权限再添加新权限。
