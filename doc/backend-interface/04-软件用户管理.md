# 软件用户管理接口

需要登录。管理应用下的软件用户（AppUser）。

---

## GET /api/user/appusers - 软件用户列表

**Query参数:**

| 参数 | 类型 | 说明 |
|------|------|------|
| page | int | 页码（默认1） |
| size | int | 每页数量（默认10） |
| keyword | string | 搜索关键词（匹配用户名/QQ/手机/邮箱） |
| app_id | int | 按应用筛选 |
| filter | string | 多选过滤，逗号分隔: paid,free,tester,expired,unexpired,unlimited,trial |

**响应:**

```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 1,
        "app_id": 1,
        "agent_id": null,
        "username": "user1",
        "status": 1,
        "is_paid": 0,
        "is_tester": 0,
        "expire_at": "2026-12-31T23:59:59Z",
        "points": 100,
        "channels": 1,
        "features": 1,
        "unbind_day": -1,
        "unbind_week": -1,
        "unbind_month": -1,
        "unbind_quarter": -1,
        "unbind_halfy": -1,
        "unbind_year": -1,
        "unbind_total": -1,
        "extra_data": "",
        "cloud_data": "",
        "invite_code": "abc12345",
        "inviter_id": null,
        "invite_count": 0,
        "rebate_points": 0,
        "qq": "",
        "wechat": "",
        "phone": "",
        "email": "",
        "is_card_user": 0,
        "is_trial": 0,
        "reg_ip": "127.0.0.1",
        "last_recharge_at": null,
        "frozen_at": null,

        "app": { "id": 1, "app_name": "..." },
        "online_count": 1
      }
    ],
    "total": 100
  }
}
```

**filter 可选值:**

| 值 | 说明 |
|------|------|
| paid | 付费用户 (is_paid=1) |
| free | 免费用户 (is_paid=0) |
| tester | 内测用户 (is_tester=1) |
| expired | 已过期 |
| unexpired | 未过期 |
| unlimited | 永久用户 (expire_at >= 2099) |
| trial | 试用用户 (is_trial=1) |

## GET /api/user/appusers/:id - 获取用户详情

**路径参数:** id - 软件用户ID

---

## POST /api/user/appusers - 创建软件用户

**请求体:**

```json
{
  "app_id": 1,              // 必填
  "username": "newuser",     // 必填
  "password": "123456",      // 必填
  "status": 1,               // 1:正常 2:封停 3:冻结
  "is_paid": 0,
  "is_tester": 0,
  "expire_at": "2026-12-31 23:59:59",
  "points": 0,
  "channels": 1,
  "features": 1,
  "unbind_day": -1,
  "unbind_week": -1,
  "unbind_month": -1,
  "unbind_quarter": -1,
  "unbind_halfy": -1,
  "unbind_year": -1,
  "unbind_total": -1,
  "extra_data": "",
  "cloud_data": "",
  "qq": "",
  "wechat": "",
  "phone": "",
  "email": ""
}
```

**说明:** 受 max_users 配额限制。同一应用下用户名唯一。

---

## PUT /api/user/appusers/:id - 更新软件用户

**请求体:** 所有字段可选（使用指针类型，传 null 不更新，传空字符串清空）

---

## DELETE /api/user/appusers/:id - 删除软件用户

**说明:** 同时删除关联的标识数据、特征码、在线会话。

---

## POST /api/user/appusers/:id/reset-invite-code - 重置推广码

**响应:**

```json
{
  "code": 0,
  "data": { "invite_code": "新推广码" }
}
```

---

## POST /api/user/appusers/batch-status - 批量更新状态

**请求体:**

```json
{
  "ids": [1, 2, 3],
  "status": 1
}
```

**响应:**

```json
{ "code": 0, "message": "更新成功", "data": { "count": 3 } }
```

---

## POST /api/user/appusers/batch-delete - 批量删除

**请求体:**

```json
{ "ids": [1, 2, 3] }
```

## 用户标识数据管理

### GET /api/user/appusers/:id/data - 标识列表

**Query参数:** page, size

**响应:**

```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 1,
        "app_user_id": 1,
        "key": "vip_level",
        "value": "3",
        "remark": "VIP等级",
        "expire_at": null,
        "created_at": "..."
      }
    ],
    "total": 1
  }
}
```

### POST /api/user/appusers/:id/data - 创建标识

**请求体:**

```json
{
  "key": "vip_level",       // 必填
  "value": "3",
  "remark": "VIP等级",
  "expire_at": "2026-12-31 23:59:59"
}
```

### PUT /api/user/appusers/:id/data/:dataId - 更新标识

### DELETE /api/user/appusers/:id/data/:dataId - 删除标识

## 用户特征码管理

### GET /api/user/appusers/:id/devices - 特征码列表

**Query参数:** page, size

**响应:**

```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 1,
        "app_user_id": 1,
        "feature": "设备特征码字符串",
        "remark": "注册绑定",
        "created_at": "..."
      }
    ],
    "total": 1,
    "features": 1  // 用户允许的特征码数量
  }
}
```

### DELETE /api/user/appusers/:id/devices/:deviceId - 删除特征码（解绑）
