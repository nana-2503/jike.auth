# 代理中心接口

代理登录后的操作接口。需要代理 JWT Token（通过 `Authorization: Bearer <token>` 传递）。

---

## POST /api/agent/login - 代理登录

**请求体:**

```json
{
  "app_code": "应用AppCode",
  "username": "代理账号",
  "password": "密码"
}
```

**成功响应:**

```json
{
  "code": 0,
  "data": {
    "token": "jwt_token",
    "agent_id": 1,
    "app_id": 1,
    "app_name": "应用名称",
    "username": "agent1",
    "nickname": "代理昵称",
    "balance": 100.00
  }
}
```

**说明:** 30分钟内最多10次失败尝试。

## GET /api/agent/cardtypes - 获取可用卡种

返回代理被授权的卡种列表及对应单价。

---

## POST /api/agent/cards/generate - 代理制卡

**请求体:**

```json
{
  "card_type_id": 1,
  "count": 100,
  "remark": "备注"
}
```

**响应:**

```json
{
  "code": 0,
  "data": {
    "cards": ["卡号1", "卡号2"],
    "batch_no": "20260101120000xxxx",
    "count": 100,
    "total_cost": 500.00,
    "balance": 500.00
  }
}
```

**说明:** 自动从代理余额扣费（单价 × 数量）。受应用所属用户的卡号配额限制。

---

## GET /api/agent/cards - 代理查卡

**Query参数:** card_type_id, batch_no, status, keyword, page, size

只能查看自己制作的卡号。

---

## GET /api/agent/card-logs - 代理制卡记录

**Query参数:** page, size

---

## GET /api/agent/users - 代理名下用户列表

**Query参数:** keyword, page, size

只能查看自己名下的用户。

---

## PUT /api/agent/users/:id/status - 封禁/解封用户

**请求体:**

```json
{ "status": 1 }  // 1:正常 2:封停
```

**说明:** 只能操作自己名下的用户。
