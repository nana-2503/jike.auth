# 套餐管理接口

需要登录。管理配额套餐。

---

## GET /api/user/packages - 套餐列表

返回所有可购买的套餐。

**响应:**

```json
{
  "code": 0,
  "data": [
    {
      "id": 1,
      "name": "基础套餐",
      "icon": "/uploads/packages/xxx.png",
      "description": "套餐描述",
      "price": 10.00,
      "duration": 30,
      "extra_apps": 5,
      "extra_users": 100,
      "extra_card_types": 10,
      "extra_cards": 1000,
      "sort": 0,
      "status": 1
    }
  ]
}
```

---

## GET /api/user/package - 获取当前套餐

返回用户当前生效的套餐信息。

---

## POST /api/user/packages/:id/buy - 购买套餐

**路径参数:** id - 套餐ID

**说明:** 从用户余额扣款，购买成功后增加额外配额，有效期为套餐的 duration 天。

---

## GET /api/user/packages/history - 套餐购买历史

**Query参数:** page, size
