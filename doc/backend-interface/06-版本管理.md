# 版本管理接口

需要登录。管理应用版本。

---

## GET /api/user/versions - 版本列表

**Query参数:** app_id, page, size

**响应数据字段:**

| 字段 | 说明 |
|------|------|
| version | 版本号字符串 |
| check_md5 | 0:不校验 1:校验MD5 |
| md5_value | MD5值 |
| is_beta | 0:正式版 1:内测版 |
| is_default | 0:否 1:默认版本 |
| status | 0:禁用 1:启用 |
| download_url | 下载链接 |
| changelog | 更新日志（Markdown） |
| published_at | 发布时间 |
| remark | 备注 |

---

## GET /api/user/versions/:id - 版本详情

---

## POST /api/user/versions - 创建版本

**请求体:**

```json
{
  "app_id": 1,
  "version": "1.0.0",
  "check_md5": 0,
  "md5_value": "",
  "is_beta": 0,
  "is_default": 1,
  "status": 1,
  "download_url": "https://...",
  "changelog": "更新内容",
  "published_at": "2026-01-01T00:00:00Z",
  "remark": ""
}
```

**说明:** 设为默认版本时自动取消其他默认版本。

---

## PUT /api/user/versions/:id - 更新版本

**请求体:** 所有字段可选

---

## DELETE /api/user/versions/:id - 删除版本
