# 用户管理接口

需要登录（JWT Token）。

---

## GET /api/user/profile - 获取个人资料

**响应:**

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "username": "test",
    "email": "test@example.com",
    "nickname": "测试用户",
    "avatar": "/uploads/avatars/xxx.jpg",
    "role": 0,
    "status": 1,
    "balance": 100.00,
    "total_spent": 50.00,
    "max_apps": -1,
    "max_users": -1,
    "max_card_types": -1,
    "max_cards": -1,
    "activity_code": "abc12345",
    "created_at": "2026-01-01T00:00:00Z",
    "updated_at": "2026-01-01T00:00:00Z"
  }
}
```

## PUT /api/user/profile - 更新个人资料

**请求体:**

```json
{ "nickname": "新昵称" }
```

**响应:**

```json
{ "code": 0, "message": "更新成功" }
```

---

## POST /api/user/avatar - 上传头像

**请求:** `multipart/form-data`

| 字段 | 类型 | 说明 |
|------|------|------|
| file | File | 图片文件，支持 JPG/PNG/GIF，最大2MB |

**响应:**

```json
{
  "code": 0,
  "message": "上传成功",
  "data": { "avatar": "/uploads/avatars/avatar_1_xxx.jpg" }
}
```

---

## POST /api/user/change-password - 修改密码

**请求体:**

```json
{
  "old_password": "旧密码",
  "new_password": "新密码"  // 至少6位
}
```

**响应:**

```json
{ "code": 0, "message": "密码修改成功，请重新登录" }
```

**说明:** 修改密码后 token_version 递增，旧 token 失效，需重新登录。

## GET /api/user/stats - 获取用户统计数据

**响应:**

```json
{
  "code": 0,
  "data": {
    "app_count": 5,
    "user_count": 100,
    "card_type_count": 10,
    "card_count": 500,
    "online_count": 20,
    "max_apps": -1,
    "max_users": -1,
    "max_card_types": -1,
    "max_cards": -1,
    "base_max_apps": -1,
    "base_max_users": -1,
    "base_max_card_types": -1,
    "base_max_cards": -1,
    "extra_apps": 0,
    "extra_users": 0,
    "extra_card_types": 0,
    "extra_cards": 0
  }
}
```

**说明:** -1 表示无限制。`max_*` = `base_max_*` + `extra_*`（套餐额外配额）

## GET /api/user/email-codes - 邮箱验证码记录

**Query参数:**

| 参数 | 类型 | 说明 |
|------|------|------|
| page | int | 页码 |
| size | int | 每页数量（最大100） |
| app_id | int | 按应用筛选 |
| type | int | 按类型筛选（1:注册 2:找回密码） |
| email | string | 按邮箱搜索 |
