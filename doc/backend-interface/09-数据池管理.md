# 数据池管理接口

需要登录。管理应用的数据池和数据项。

---

## 数据池

### GET /api/user/datapools - 数据池列表

**Query参数:** page, size

### POST /api/user/datapools - 创建数据池

**请求体:**

```json
{
  "app_id": 1,
  "name": "数据池名称",
  "code": "pool_code",
  "sort": 0,
  "require_login": 0,
  "remark": ""
}
```

**字段说明:**

| 字段 | 说明 |
|------|------|
| code | 数据池编码，用于SDK调用 |
| require_login | 0:客户端无需登录即可添加 1:需要登录 |

### GET /api/user/datapools/:id - 数据池详情

### PUT /api/user/datapools/:id - 更新数据池

### DELETE /api/user/datapools/:id - 删除数据池

---

## 数据项

### GET /api/user/dataitems/:poolId - 数据项列表

**Query参数:** page, size

### POST /api/user/dataitems/:poolId - 创建数据项

**请求体:**

```json
{
  "name": "数据名称",
  "code": "item_code",
  "content": "数据内容（支持长文本）",
  "modify_count": -1,
  "expire_at": "2026-12-31 23:59:59",
  "require_login": 0,
  "require_paid": 0,
  "allow_delete": 0,
  "allow_modify": 0,
  "allow_expire": 0,
  "remark": ""
}
```

**字段说明:**

| 字段 | 说明 |
|------|------|
| modify_count | 可修改次数，-1=无限 |
| require_login | 0:无需登录 1:需要登录 |
| require_paid | 0:免费可见 1:需付费用户 |
| allow_delete | 0:不允许客户端删除 1:允许 |
| allow_modify | 0:不允许客户端修改 1:允许 |
| allow_expire | 0:不允许过期修改 1:允许 |

### GET /api/user/dataitems/:poolId/:itemId - 数据项详情

### PUT /api/user/dataitems/:poolId/:itemId - 更新数据项

### DELETE /api/user/dataitems/:poolId/:itemId - 删除数据项
