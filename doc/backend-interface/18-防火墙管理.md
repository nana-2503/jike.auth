# 防火墙管理接口

需要登录。管理黑名单和防火墙规则。

---

## 黑名单管理

### GET /api/user/blacklist - 黑名单列表

**Query参数:** page, size

### POST /api/user/blacklist - 添加黑名单

**请求体:**

```json
{
  "app_id": 1,
  "type": "ip",
  "value": "192.168.1.1",
  "remark": "恶意访问",
  "expire_at": "2026-12-31 23:59:59"
}
```

### PUT /api/user/blacklist/:id - 更新黑名单

### DELETE /api/user/blacklist/:id - 删除黑名单

### POST /api/user/blacklist/batch-delete - 批量删除黑名单

**请求体:**

```json
{ "ids": [1, 2, 3] }
```

## 防火墙配置

### GET /api/user/firewall/config - 获取防火墙配置

### POST /api/user/firewall/config - 保存防火墙配置

---

## 防火墙日志

### GET /api/user/firewall/logs - 防火墙日志列表

**Query参数:** page, size

### DELETE /api/user/firewall/logs - 清空防火墙日志

---

## 登录锁定

### GET /api/user/firewall/locks - 登录锁定列表

### POST /api/user/firewall/unlock - 解锁登录IP

**请求体:**

```json
{ "ip": "192.168.1.1" }
```
