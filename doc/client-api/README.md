# 极客验证系统

一站式软件授权验证平台，为软件开发者提供完整的用户管理、授权验证、卡密系统和运营工具。

## 技术架构

- 后端：Go + Gin + GORM
- 前端：React + TypeScript + HeroUI
- 数据库：MySQL / MariaDB / PostgreSQL
- 通讯协议：HTTP REST API + WebSocket
- 构建产物：Windows amd64 / Linux amd64 / Linux arm64

## 核心功能

### 应用管理
- 多应用支持，每个应用独立配置
- 应用编码（AppCode）、密钥（AppKey）、通讯密钥（AppSecret）三重标识
- 支持账号登录、卡密登录、账号+卡密三种登录模式
- 计费模式：免费 / 计时 / 计点
- 设备绑定：单绑定通道 / 账户总通道
- 注册模式：关闭 / 开放 / 需充值卡 / 限次数

### 用户管理
- 软件用户按应用隔离，独立管理
- 用户状态：正常 / 封停 / 冻结
- 内测账户标记
- 用户标识数据（自定义键值对，支持过期时间）
- 云端数据存储
- 附加数据
- 设备特征码管理与解绑（支持天/周/月/季/半年/年/总次数限制）
- 推广码与邀请关系链

### 卡密系统
- 自定义卡种：时长 / 点数 / 通道数 / 特征数
- 灵活制卡规则：大小写字母+数字组合，自定义卡号长度和前缀
- 批次管理，支持批量导出（文本/Excel）
- 单卡可充值次数 & 每用户可充值次数限制
- 离线充值（无需登录即可充值）

### 版本管理
- 多版本发布，支持默认版本和内测版本
- MD5 校验
- 更新日志（Markdown）
- 下载链接管理

### 在线会话管理
- 实时在线用户列表
- 在线统计图表
- 踢人下线（单用户/批量）
- 客户端异常/崩溃日志上报与后台排查
- 心跳检测与自动清理

## 特色功能 ⭐

### 🔐 AES-CBC 通讯加密
HTTP 和 WebSocket 接口均支持 AES-CBC 加密通讯，密钥自动规范化（16/24/32字节），随机 IV + PKCS7 填充，防止数据被抓包篡改。

### ✍️ 双签名算法
- 服务端签名算法（ServerSignAlgo）：服务端验证客户端请求合法性
- 客户端签名算法（SignAlgo）：客户端验证服务端响应真实性
- 签名模板支持自定义，`[data]` 和 `[key]` 占位符替换后 SHA-256 哈希

### 🌐 WebSocket 长连接
除 HTTP REST API 外，提供完整的 WebSocket 接口，支持所有公开和认证操作，适用于需要保持长连接的客户端场景。被踢下线实时推送通知。

### 🛡️ 应用级防火墙
每个应用独立配置防火墙策略：
- IP 白名单 / 黑名单
- IP 并发限制 & 频率限制
- IP 地区限制（白名单/黑名单模式）
- 登录失败次数限制与自动锁定
- API 调用频率限制
- 心跳检测容差
- 重放攻击防护
- 自动封禁（登录失败超限/频率超限自动封 IP）

### 🎰 活动系统
- 转盘抽奖：自定义奖品概率（万分比）、库存控制
- 定时抽奖：设定开奖时间，自动开奖
- 卡号发放：活动直接发放卡密
- 独立活动页面，软件用户登录参与

### 👥 代理系统
- 独立代理账号与登录面板
- 代理余额管理与充值
- 按卡种授权，自定义制卡单价
- 代理制卡记录与流水

### 📣 推广返利
- 邀请码机制，自动建立推广关系链
- 注册奖励积分
- 消费返利（按卡种固定返利积分）
- 返利排行榜与邀请树可视化
- 签名验证
- 自动重试 & 超时配置
- 完整的推送日志

### 📋 提卡系统
- 提卡 Key 管理，独立密钥与额度控制
- 公开提卡接口，适用于发卡平台对接
- 按卡种定价，自动扣减额度
- 提卡记录与流水

### 🔑 授权证书
- 证书生成与加密
- 绑定特征码
- 使用次数限制
- 证书验证日志

### ☁️ 云盘集成
- 对接 FilesBox 网盘
- 文件管理：上传、下载、重命名、移动、复制
- 文件直链获取
- 分享管理 & 回收站
- 在线编辑文件内容

### 🎯 其他特色
- **签到系统**：每日签到奖励余额，连续签到额外奖励，可自定义规则
- **工单系统**：用户提交工单，管理员回复，支持 Markdown
- **Telegram 通知**：注册/套餐购买等事件推送到 TG 群
- **邮箱验证**：注册邮箱验证码、找回密码
- **数据池**：公共数据存储，支持权限控制（登录/修改/删除/过期）
- **积分商城**：推广返利积分可兑换点数、时长或卡密
- **套餐系统**：用户购买套餐扩展应用数/用户数/卡种数/卡号数配额
- **数据备份**：一键导出/导入全量数据
- **批量维护工具**：批量清理卡密、踢人、封停、加时加点、解绑等
- **操作日志**：完整记录所有管理操作
- **异常日志**：SDK 上报客户端异常、崩溃堆栈、运行环境和上下文
- **黑名单**：IP / 特征码封禁，支持过期时间
- **主题定制**：自定义主题色、页面动画效果
- **图形验证码**：登录失败后自动触发

## SDK 支持

### HTTP SDK
标准 REST API，完整的接口文档，支持加密通讯和签名验证。

### WebSocket SDK
- Node.js SDK（`sdk/ws/nodejs/`）：完整封装所有 WS 接口，支持加密/签名/自动心跳

## 部署

### 默认配置
- 端口：8081
- 默认管理员：`admin` / `admin123`
- 配置文件：`config.yaml`（与可执行文件同目录）

### 构建
```bash
# Windows 下执行
build.bat
```
产物输出到 `release/` 目录：
- `release/windows-amd64/server` + `config.yaml`
- `release/linux-amd64/server` + `config.yaml`
- `release/linux-arm64/server` + `config.yaml`

### 数据库
支持 MySQL、MariaDB、PostgreSQL，首次启动自动建表和创建默认管理员账号。
