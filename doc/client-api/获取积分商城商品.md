# 获取积分商城商品

## 基本信息

- 路径: `POST /api/sdk/point-shop/items`
- 需要登录: 是
- 需要加密: 是（请求加密 + 响应加密）
- 用途: 获取当前应用可兑换的积分商城商品和当前用户返利积分余额。

## 请求参数

### Header

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| X-Token | string | 是 | 登录返回的 token |

### Body

无业务参数。

### 公共参数（包含在 data 中）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| feature | string | 是 | 设备特征码 |
| version | string | 是 | 客户端版本号 |
| client_id | string | 是 | 客户端 ID |
| client_os | string | 否 | 客户端操作系统 |
| md5 | string | 否 | 应用版本 MD5 值 |
| uuid | string | 是 | 随机 UUID |

## 请求示例

```json
{
  "app_code": "1234-56789012",
  "data": "Base64加密字符串...",
  "sign": "签名字符串..."
}
```

## 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "points": 1200,
    "list": [
      {
        "id": 1,
        "name": "兑换100点",
        "description": "返利积分兑换软件点数",
        "cost": 100,
        "reward_type": 1,
        "reward_points": 100,
        "stock": -1,
        "exchanged_count": 12
      }
    ]
  },
  "time": 1704067200
}
```

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| points | int | 当前用户返利积分余额 |
| reward_type | int | 奖励类型：1=点数，2=时长，3=卡密 |
| reward_points | int | 点数奖励数量，仅 `reward_type=1` 返回 |
| reward_duration | int | 时长奖励，单位分钟，-1 表示永久，仅 `reward_type=2` 返回 |
| card_type | object/null | 卡密奖励关联的卡种，仅 `reward_type=3` 返回 |
| stock | int | 库存，-1 表示不限 |
| exchanged_count | int | 已兑换次数 |

> 商品只会返回当前奖励类型相关的奖励字段。例如点数商品只返回 `reward_points`，不会返回 `reward_duration` 或 `card_type`。

## 错误响应

| 错误码 | 说明 |
|--------|------|
| 201 | 缺少令牌 / 会话不存在或已过期 |
| 214 | 版本校验失败 |
