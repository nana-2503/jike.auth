# 设置云端数据

## 基本信息

- 路径: `POST /api/sdk/clouddata/set`
- 需要登录: 是
- 需要加密: 是（如应用配置了加密）

## 请求参数

### Header

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| X-Token | string | 是 | 登录返回的token |

### 业务参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| cloud_data | string | 是 | 要保存的云端数据 |

## 加解密流程

详见 [加解密流程.md](加解密流程.md)（已登录接口通用流程）。

## 签名验证流程

详见 [签名流程.md](签名流程.md)（已登录接口通用流程）。

## 接口逻辑处理流程

1. 从 Header 获取 X-Token，查找会话
2. 解密请求数据
3. 更新用户的 cloud_data 字段

## 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": null,
  "time": 1704067200
}
```

## 错误响应

| 错误码 | 说明 |
|--------|------|
| 201 | 缺少令牌 / 会话不存在或已过期 |
| 202 | 会话不存在 |
