# 签名流程

> 签名使用 SHA-256，基于应用配置的签名算法模板计算。未配置签名算法时跳过签名验证。

## 模板变量

| 变量 | 说明 |
|------|------|
| `[data]` | 替换为加密后的 data 值（Base64 字符串） |
| `[key]` | 替换为 AppKey |

## 模板示例

```
[data][key]
[key]_[data]_salt
```

## 计算步骤

1. 将模板中的 `[data]` 替换为加密后的 data 字符串
2. 将模板中的 `[key]` 替换为 AppKey
3. 对替换后的完整字符串计算 SHA-256 哈希

## 签名方向

| 场景 | 使用的算法模板 | 说明 |
|------|---------------|------|
| 客户端发送请求 | 服务端签名算法（ServerSignAlgo） | 客户端用此算法签名，服务端验证 |
| 服务端返回响应 | 客户端签名算法（SignAlgo） | 服务端用此算法签名，客户端验证 |

## 未登录接口

客户端将业务参数 + 公共参数组成 JSON → AES 加密得到 data → 使用 **服务端签名算法** 计算 sign → 发送 `{ app_code, data, sign }`

## 已登录接口

客户端将业务参数 + 公共参数组成 JSON → AES 加密得到 data → 使用 **服务端签名算法** 计算 sign → 发送 `{ app_code, data, sign }`（Header 携带 X-Token）
