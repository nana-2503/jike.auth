# 上传用户头像

## 基本信息

- 路径: `POST /api/sdk/avatar`
- 需要登录: 是
- 请求类型: `multipart/form-data`
- 需要加密: 否（文件直传），响应加密

## 客户端怎么请求

这个接口不是把文件放进 `data` 里加密上传，而是直接发 `multipart/form-data`：

- 请求头带 `X-Token`
- 表单里带 `app_code`
- 表单里带 `file`
- 不需要传 `data` 和 `sign`

客户端可直接用 `FormData` 构造请求。

## 请求参数

### Header

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| X-Token | string | 是 | 登录返回的token |

### FormData

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_code | string | 是 | 应用AppCode |
| file | file | 是 | 头像文件，支持 JPG/PNG/GIF/WebP，最大 2MB |

## 接口逻辑处理流程

1. 读取 `app_code`，验证应用存在且启用
2. 从 Header 获取 `X-Token`，查找当前在线会话
3. 检查会话超时
4. 校验上传文件格式和大小
5. 保存到 `uploads/app-user-avatars/{app_id}/{app_user_id}/avatar.{ext}`
6. 更新当前软件用户的 `avatar` 字段
7. 返回头像访问 URL

## 请求示例

### JavaScript / TypeScript

```ts
const form = new FormData()
form.append('app_code', appCode)
form.append('file', file)

await fetch('/api/sdk/avatar', {
  method: 'POST',
  headers: {
    'X-Token': token,
  },
  body: form,
})
```

### HTTP

```http
POST /api/sdk/avatar HTTP/1.1
X-Token: your-login-token
Content-Type: multipart/form-data

app_code=1234-56789012
file=@avatar.png
```

> `Content-Type` 由客户端库自动带上边界（boundary），一般不要手动拼字符串。

## 成功响应

响应外层为加密格式：

```json
{
  "data": "AES加密后的Base64字符串...",
  "sign": "签名字符串..."
}
```

`data` 解密后：

```json
{
  "code": 0,
  "message": "上传成功",
  "data": {
    "avatar": "/uploads/app-user-avatars/1/23/avatar.png"
  },
  "time": 1704067200
}
```

## 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| avatar | string | 头像访问URL |

## 错误响应

| 错误码 | 说明 |
|--------|------|
| 201 | 缺少参数、缺少令牌、文件格式/大小不合法 |
| 202 | 应用不存在或已禁用 |
| 203 | 会话不存在或已过期 / 用户不存在 |
| 500 | 文件保存或数据库更新失败 |
