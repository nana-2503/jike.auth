# 获取积分商城兑换记录

## 基本信息

- 路径: `POST /api/sdk/point-shop/exchanges`
- 需要登录: 是
- 需要加密: 是（请求加密 + 响应加密）
- 用途: 获取当前软件用户最近的积分商城兑换记录。

## 请求参数

### Header

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| X-Token | string | 是 | 登录返回的 token |

### Body

无业务参数。

### 公共参数（包含在 data 中）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| feature | string | 是 | 设备特征码 |
| version | string | 是 | 客户端版本号 |
| client_id | string | 是 | 客户端 ID |
| client_os | string | 否 | 客户端操作系统 |
| md5 | string | 否 | 应用版本 MD5 值 |
| uuid | string | 是 | 随机 UUID |

## 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": 10,
      "item_name": "兑换100点",
      "cost": 100,
      "reward_type": 1,
      "reward_value": "增加100点",
      "card_no": "",
      "created_at": "2026-05-09T10:30:00+08:00"
    }
  ],
  "time": 1704067200
}
```

## 错误响应

| 错误码 | 说明 |
|--------|------|
| 201 | 缺少令牌 / 会话不存在或已过期 |
| 214 | 版本校验失败 |
