# SDK 接口文档总览

## 基础信息

- 基础路径: `/api/sdk`
- 通讯加密: AES-256-CBC（详见 [通讯加密说明.md](通讯加密说明.md)）
- 签名算法: SHA-256（详见 [通讯加密说明.md](通讯加密说明.md)）
- 加解密流程: [加解密流程.md](加解密流程.md)
- 签名流程: [签名流程.md](签名流程.md)
- WebSocket 接口: [WebSocket接口.md](WebSocket接口.md)

## 公共参数

所有接口的 data 中可包含以下公共参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| feature | string | 是 | 设备特征码 |
| version | string | 是 | 客户端版本号 |
| client_id | string | 是 | 客户端ID（每次启动固定） |
| client_os | string | 否 | 客户端操作系统 |
| md5 | string | 否 | 应用版本MD5值 |
| uuid | string | 是 | 随机UUID（每次请求随机生成，用于匹配响应） |

## 通用错误码

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 201 | 参数缺失或无效 |
| 202 | 应用不存在或已禁用 |
| 214 | 版本校验失败（版本不存在、已禁用、低于最低版本或MD5不匹配） |
| 215 | 邮箱验证码错误或已过期 |
| 216 | 需要图形验证码 |

> 各接口的专属错误码请参考对应文档。
