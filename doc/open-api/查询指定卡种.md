# 查询指定卡种

## 基本信息

- 路径: `GET /api/open/cardtype?app_code=xxx&name=xxx`
- 需要权限: `cardtypes:get`

## 查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_code | string | 是 | 应用编码 |
| name | string | 是 | 卡种名称 |

## 请求示例

```bash
curl -sS -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  "http://localhost:8080/api/open/cardtype?app_code=2604-AB12CD34&name=%E6%9C%88%E5%8D%A1"
```
