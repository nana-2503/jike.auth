# 查询应用列表

## 基本信息

- 路径: `GET /api/open/apps`
- 需要权限: `apps:list`

## 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认 1；小于 1 时按 1 处理 |
| size | int | 否 | 每页数量，默认 20，**最大 100**；小于 1 时按 20 处理 |

## 请求示例

```bash
curl -sS -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  "http://localhost:8080/api/open/apps?page=1&size=20"
```

## 成功响应

```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 1,
        "app_name": "测试应用",
        "app_key": "xxxxxxxxxxxxxxxx",
        "app_code": "1234-56789012",
        "description": "应用描述",
        "login_mode": 1,
        "billing_mode": 1,
        "status": 1,
        "created_at": "2024-01-01T00:00:00Z"
      }
    ],
    "total": 1
  }
}
```

## 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 应用ID |
| app_name | string | 应用名称 |
| app_key | string | 应用Key |
| app_code | string | 应用编码 |
| description | string | 应用描述 |
| login_mode | int | 登录模式（1:账号 2:卡密 3:两者） |
| billing_mode | int | 计费模式（1:免费 2:计时 3:计点） |
| status | int | 状态（0:禁用 1:正常） |
| created_at | string | 创建时间 |
