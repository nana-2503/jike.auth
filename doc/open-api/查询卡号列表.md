# 查询卡号列表

## 基本信息

- 路径: `GET /api/open/cards`
- 需要权限: `cards:list`

## 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_code | string | 是 | 应用编码 |
| status | int | 否 | 按状态筛选（1:未使用 2:已使用 3:已禁用） |
| keyword | string | 否 | 按卡号模糊搜索 |
| page | int | 否 | 页码，默认 1；小于 1 时按 1 处理 |
| size | int | 否 | 每页数量，默认 20，**最大 100**；小于 1 时按 20 处理 |

## 请求示例

```bash
curl -sS -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  "http://localhost:8080/api/open/cards?app_code=2604-AB12CD34&status=1&keyword=MK&page=1&size=20"
```

## 成功响应

```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 1,
        "app_code": "1234-56789012",
        "card_type_name": "月卡",
        "card_no": "MK-XXXXXXXXXXXX",
        "status": 1,
        "used_count": 0,
        "batch_no": "B20240101001",
        "remark": "",
        "used_at": null,
        "created_at": "2024-01-01T00:00:00Z"
      }
    ],
    "total": 1
  }
}
```

## 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 卡号ID |
| app_code | string | 所属应用编码 |
| card_type_name | string | 所属卡种名称 |
| card_no | string | 卡号 |
| status | int | 状态（1:未使用 2:已使用 3:已禁用） |
| used_count | int | 已使用次数 |
| batch_no | string | 批次号 |
| remark | string | 备注 |
| used_at | string | 使用时间 |
| created_at | string | 创建时间 |
