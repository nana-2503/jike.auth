# 新增卡种

## 基本信息

- 路径: `POST /api/open/cardtypes`
- 需要权限: `cardtypes:create`

## 请求参数（JSON Body）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_code | string | 是 | 所属应用编码 |
| name | string | 是 | 卡种名称 |
| category | int | 否 | 分类（1:充值卡 2:登录卡），默认 1 |
| prefix | string | 否 | 卡号前缀 |
| points | int | 否 | 点数 |
| rebate_points | int | 否 | 消费返利积分，充值成功后固定发放给直接上级，0=不返利 |
| duration | int | 否 | 时长（分钟），-1为永久 |
| gen_rule | int | 否 | 生成规则（同后台卡种设置），默认 1 |
| max_use | int | 否 | 最大使用次数，默认 1 |
| max_user_use | int | 否 | 单用户最大使用次数，默认 1 |
| channels | int | 否 | 通道数，默认 1 |
| features | int | 否 | 特征数，默认 1 |
| unbind_day | int | 否 | 日解绑次数（默认 -1） |
| unbind_week | int | 否 | 周解绑次数（默认 -1） |
| unbind_month | int | 否 | 月解绑次数（默认 -1） |
| unbind_halfy | int | 否 | 半年解绑次数（默认 -1） |
| unbind_year | int | 否 | 年解绑次数（默认 -1） |
| unbind_total | int | 否 | 总解绑次数（默认 -1） |
| card_length | int | 否 | 卡号长度（最小 12），默认 16 |
| extra_data | string | 否 | 附加数据 |
| remark | string | 否 | 备注 |
| withdraw_price | number | 否 | 提现单价 |

## 请求示例

```bash
curl -sS -X POST "http://localhost:8080/api/open/cardtypes" ^
  -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  -H "Content-Type: application/json" ^
  -d "{\"app_code\":\"2604-AB12CD34\",\"name\":\"月卡\",\"prefix\":\"MK\",\"card_length\":20,\"duration\":43200}"
```

## 成功响应

```json
{
  "code": 0,
  "message": "创建成功"
}
```
