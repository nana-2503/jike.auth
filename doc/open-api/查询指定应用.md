# 查询指定应用

## 基本信息

- 路径: `GET /api/open/apps/:id`
- 需要权限: `apps:get`

## 路径参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | 是 | 应用ID（可通过“查询应用列表”接口获取） |

## 请求示例

```bash
curl -sS -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  "http://localhost:8080/api/open/apps/1"
```

## 成功响应

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "app_name": "测试应用",
    "app_key": "xxxxxxxxxxxxxxxx",
    "app_code": "1234-56789012",
    "description": "应用描述",
    "login_mode": 1,
    "billing_mode": 1,
    "heartbeat": 60,
    "bind_device": 1,
    "channel_mode": 1,
    "reg_mode": 2,
    "status": 1,
    "created_at": "2024-01-01T00:00:00Z"
  }
}
```

## 错误响应

| 错误码 | 说明 |
|--------|------|
| 1 | 应用不存在 |
