# 查询卡种列表

## 基本信息

- 路径: `GET /api/open/cardtypes`
- 需要权限: `cardtypes:list`

## 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_code | string | 是 | 应用编码 |
| page | int | 否 | 页码，默认 1；小于 1 时按 1 处理 |
| size | int | 否 | 每页数量，默认 20，**最大 100**；小于 1 时按 20 处理 |

## 请求示例

```bash
curl -sS -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  "http://localhost:8080/api/open/cardtypes?app_code=2604-AB12CD34&page=1&size=20"
```

## 成功响应

```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": 1,
        "app_code": "1234-56789012",
        "app_name": "测试应用",
        "name": "月卡",
        "prefix": "MK",
        "card_length": 20,
        "duration": 43200,
        "points": 0,
        "category": 1,
        "max_use": 1,
        "status": 1,
        "created_at": "2024-01-01T00:00:00Z"
      }
    ],
    "total": 1
  }
}
```

## 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 卡种ID |
| app_code | string | 所属应用编码 |
| app_name | string | 所属应用名称 |
| name | string | 卡种名称 |
| prefix | string | 卡号前缀 |
| card_length | int | 卡号长度 |
| duration | int | 时长（分钟），-1为永久 |
| points | int | 点数 |
| category | int | 分类（1:充值卡 2:登录卡） |
| max_use | int | 最大使用次数 |
| status | int | 状态（0:禁用 1:正常） |
