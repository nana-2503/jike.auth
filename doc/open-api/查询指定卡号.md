# 查询指定卡号

## 基本信息

- 路径: `GET /api/open/cards/:card_no`
- 需要权限: `cards:get`

## 路径参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| card_no | string | 是 | 卡号 |

## 查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_code | string | 是 | 应用编码 |

## 请求示例

```bash
curl -sS -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  "http://localhost:8080/api/open/cards/MK-XXXXXXXXXXXX?app_code=2604-AB12CD34"
```

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "app_code": "1234-56789012",
    "card_type_name": "月卡",
    "card_no": "MK-XXXXXXXXXXXX",
    "status": 1,
    "used_count": 0,
    "batch_no": "B20240101001",
    "remark": "",
    "used_at": null,
    "created_at": "2024-01-01T00:00:00Z",
    "card_type": {

  }
}
```

## 错误响应

| 错误码 | 说明 |
|--------|------|
| 1 | 卡号不存在 / 无权访问 |
