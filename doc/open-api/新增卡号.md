# 新增卡号

## 基本信息

- 路径: `POST /api/open/cards`
- 需要权限: `cards:create`

## 请求参数（JSON Body）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_code | string | 是 | 所属应用编码 |
| card_type_name | string | 是 | 卡种名称 |
| card_no | string | 是 | 卡号字符串（全局唯一） |
| batch_no | string | 否 | 批次号，不传默认 `manual` |
| status | int | 否 | 状态（1:未使用 2:已使用 3:已禁用），不传默认 1 |
| remark | string | 否 | 备注 |

## 请求示例

```bash
curl -sS -X POST "http://localhost:8080/api/open/cards" ^
  -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  -H "Content-Type: application/json" ^
  -d "{\"app_code\":\"2604-AB12CD34\",\"card_type_name\":\"月卡\",\"card_no\":\"MK-XXXXXXXXXXXX\",\"remark\":\"手动导入\"}"
```

## 成功响应

```json
{
  "code": 0,
  "message": "创建成功"
}
```
