# 编辑应用

## 基本信息

- 路径: `PUT /api/open/apps/:id`
- 需要权限: `apps:update`

## Path 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | 是 | 应用ID（可通过“查询应用列表”接口获取） |

## 请求参数（JSON Body）

以下字段均为可选，传什么改什么：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_name | string | 否 | 应用名称 |
| description | string | 否 | 应用描述 |
| login_mode | int | 否 | 登录模式（1:账号 2:卡密 3:两者） |
| billing_mode | int | 否 | 计费模式（1:免费 2:计时 3:计点） |
| heartbeat | int | 否 | 心跳间隔（秒），最小 10 |
| crypto_mode | string | 否 | 加密模式 |
| app_secret | string | 否 | 应用密钥 |
| sign_algo | string | 否 | 签名算法 |
| server_sign_algo | string | 否 | 服务端签名算法 |
| bind_device | int | 否 | 是否绑定设备 |
| channel_mode | int | 否 | 通道模式（1/2） |
| login_kick | int | 否 | 顶号策略 |
| reg_mode | int | 否 | 注册模式（1~4） |
| reg_limit | int | 否 | 注册限制（>=1） |
| reg_channels | int | 否 | 注册通道数 |
| reg_features | int | 否 | 注册特征数 |
| reg_duration | int | 否 | 注册赠送时长（分钟） |
| reg_points | int | 否 | 注册赠送点数 |
| trial_duration | int | 否 | 试用时长（分钟） |
| trial_points | int | 否 | 试用点数 |
| trial_limit | int | 否 | 试用次数限制 |
| maintenance | int | 否 | 维护模式（按系统原有约定） |
| status | int | 否 | 状态（0:禁用 1:正常） |

## 请求示例

```bash
curl -sS -X PUT "http://localhost:8080/api/open/apps/1" ^
  -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  -H "Content-Type: application/json" ^
  -d "{\"description\":\"新的描述\",\"status\":1}"
```

## 成功响应

```json
{
  "code": 0,
  "message": "更新成功"
}
```
