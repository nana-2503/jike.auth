# 新增用户

## 基本信息

- 路径: `POST /api/open/users`
- 需要权限: `users:create`

## 请求参数（JSON Body）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_code | string | 是 | 所属应用编码 |
| username | string | 是 | 用户名（同一应用下唯一） |
| password | string | 是 | 密码（服务端会加密存储） |
| status | int | 否 | 状态（1:正常 2:封停 3:冻结），默认 1 |
| is_paid | int | 否 | 是否付费（0/1） |
| is_tester | int | 否 | 是否内测（0/1） |
| expire_at | string | 否 | 到期时间（字符串时间格式，留空表示不设置） |
| points | int | 否 | 点数余额 |
| channels | int | 否 | 通道数，默认 1 |
| features | int | 否 | 特征数，默认 1 |
| extra_data | string | 否 | 附加数据 |
| cloud_data | string | 否 | 云端数据 |
| qq | string | 否 | QQ号 |
| wechat | string | 否 | 微信 |
| phone | string | 否 | 手机 |
| email | string | 否 | 邮箱 |

## 请求示例

```bash
curl -sS -X POST "http://localhost:8080/api/open/users" ^
  -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  -H "Content-Type: application/json" ^
  -d "{\"app_code\":\"2604-AB12CD34\",\"username\":\"testuser\",\"password\":\"123456\",\"status\":1}"
```

## 成功响应

```json
{
  "code": 0,
  "message": "创建成功"
}
```
