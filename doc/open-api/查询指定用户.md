# 查询指定用户

## 基本信息

- 路径: `GET /api/open/user?app_code=xxx&username=xxx`
- 需要权限: `users:get`

## 查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_code | string | 是 | 应用编码 |
| username | string | 是 | 用户名 |

## 请求示例

```bash
curl -sS -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  "http://localhost:8080/api/open/user?app_code=2604-AB12CD34&username=testuser"
```

## 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 用户ID |
| app_code | string | 所属应用编码 |
| app_name | string | 所属应用名称 |
| username | string | 用户名 |
| status | int | 状态（1:正常 2:封停 3:冻结） |
| is_paid | int | 是否付费（0:否 1:是） |
| is_tester | int | 是否内测（0:否 1:是） |
| is_card_user | int | 是否卡密用户（0:否 1:是） |
| is_trial | int | 是否试用（0:否 1:是） |
| expire_at | string | 到期时间 |
| points | int | 点数余额 |
| rebate_points | int | 返利点数 |
| channels | int | 通道数 |
| features | int | 特征数 |
| invite_code | string | 邀请码 |
| invite_count | int | 邀请人数 |
| qq | string | QQ号 |
| wechat | string | 微信号 |
| phone | string | 手机号 |
| email | string | 邮箱 |
| reg_ip | string | 注册IP |
| created_at | string | 注册时间 |

## 错误响应

| 错误码 | 说明 |
|--------|------|
| 1 | 用户不存在 / 无权访问 |
