# 编辑用户

## 基本信息

- 路径: `PUT /api/open/users/:id`
- 需要权限: `users:update`

## Path 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | 是 | 用户ID（可通过“查询用户列表”接口获取） |

## 请求参数（JSON Body）

以下字段均为可选，传什么改什么：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 否 | 新用户名（同一应用下唯一） |
| password | string | 否 | 新密码 |
| status | int | 否 | 状态（1:正常 2:封停 3:冻结） |
| is_paid | int | 否 | 是否付费（0/1） |
| is_tester | int | 否 | 是否内测（0/1） |
| expire_at | string | 否 | 到期时间；传空字符串表示清空 |
| points | int | 否 | 点数余额 |
| channels | int | 否 | 通道数 |
| features | int | 否 | 特征数 |
| extra_data | string | 否 | 附加数据 |
| cloud_data | string | 否 | 云端数据 |
| qq | string | 否 | QQ号 |
| wechat | string | 否 | 微信 |
| phone | string | 否 | 手机 |
| email | string | 否 | 邮箱 |

## 请求示例

```bash
curl -sS -X PUT "http://localhost:8080/api/open/users/1" ^
  -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  -H "Content-Type: application/json" ^
  -d "{\"points\":200,\"expire_at\":\"2026-12-31 23:59:59\"}"
```

## 成功响应

```json
{
  "code": 0,
  "message": "更新成功"
}
```
