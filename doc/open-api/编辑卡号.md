# 编辑卡号

## 基本信息

- 路径: `PUT /api/open/cards/:id`
- 需要权限: `cards:update`

## Path 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | 是 | 卡号ID（可通过“查询卡号列表”接口获取） |

## 请求参数（JSON Body）

以下字段均为可选，传什么改什么：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | int | 否 | 状态（1:未使用 2:已使用 3:已禁用） |
| batch_no | string | 否 | 批次号 |
| remark | string | 否 | 备注 |

## 请求示例

```bash
curl -sS -X PUT "http://localhost:8080/api/open/cards/1" ^
  -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  -H "Content-Type: application/json" ^
  -d "{\"status\":3,\"remark\":\"禁用\"}"
```

## 成功响应

```json
{
  "code": 0,
  "message": "更新成功"
}
```
