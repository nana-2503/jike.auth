# 编辑卡种

## 基本信息

- 路径: `PUT /api/open/cardtypes/:id`
- 需要权限: `cardtypes:update`

## Path 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | 是 | 卡种ID（可通过“查询卡种列表”接口获取） |

## 请求参数（JSON Body）

以下字段均为可选，传什么改什么：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 否 | 卡种名称（允许修改） |
| category | int | 否 | 分类 |
| prefix | string | 否 | 卡号前缀 |
| points | int | 否 | 点数 |
| rebate_points | int | 否 | 消费返利积分，充值成功后固定发放给直接上级，0=不返利 |
| duration | int | 否 | 时长（分钟） |
| gen_rule | int | 否 | 生成规则 |
| max_use | int | 否 | 最大使用次数 |
| max_user_use | int | 否 | 单用户最大使用次数 |
| channels | int | 否 | 通道数 |
| features | int | 否 | 特征数 |
| unbind_day | int | 否 | 日解绑次数 |
| unbind_week | int | 否 | 周解绑次数 |
| unbind_month | int | 否 | 月解绑次数 |
| unbind_halfy | int | 否 | 半年解绑次数 |
| unbind_year | int | 否 | 年解绑次数 |
| unbind_total | int | 否 | 总解绑次数 |
| card_length | int | 否 | 卡号长度（最小 12） |
| extra_data | string | 否 | 附加数据 |
| remark | string | 否 | 备注 |
| withdraw_price | number | 否 | 提现单价 |

## 请求示例

```bash
curl -sS -X PUT "http://localhost:8080/api/open/cardtypes/1" ^
  -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  -H "Content-Type: application/json" ^
  -d "{\"points\":100,\"remark\":\"更新备注\"}"
```

## 成功响应

```json
{
  "code": 0,
  "message": "更新成功"
}
```
