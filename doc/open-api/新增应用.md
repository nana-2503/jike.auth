# 新增应用

## 基本信息

- 路径: `POST /api/open/apps`
- 需要权限: `apps:create`

## 请求参数（JSON Body）

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_name | string | 是 | 应用名称 |
| description | string | 否 | 应用描述 |
| login_mode | int | 否 | 登录模式（1:账号 2:卡密 3:两者），默认 1 |
| billing_mode | int | 否 | 计费模式（1:免费 2:计时 3:计点），默认 1 |
| heartbeat | int | 否 | 心跳间隔（秒），最小 10，默认 60 |
| crypto_mode | string | 否 | 加密模式，默认 `aes-256-cbc` |
| app_secret | string | 否 | 应用密钥，不传则自动生成 |
| sign_algo | string | 否 | 签名算法 |
| server_sign_algo | string | 否 | 服务端签名算法 |
| bind_device | int | 否 | 是否绑定设备（按系统原有约定） |
| channel_mode | int | 否 | 通道模式（1/2），默认 1 |
| login_kick | int | 否 | 顶号策略（按系统原有约定） |
| reg_mode | int | 否 | 注册模式（1~4），默认 1 |
| reg_limit | int | 否 | 注册限制，最小 1，默认 1 |
| reg_channels | int | 否 | 注册通道数 |
| reg_features | int | 否 | 注册特征数 |
| reg_duration | int | 否 | 注册赠送时长（分钟） |
| reg_points | int | 否 | 注册赠送点数 |
| trial_duration | int | 否 | 试用时长（分钟） |
| trial_points | int | 否 | 试用点数 |
| trial_limit | int | 否 | 试用次数限制 |

## 请求示例

```bash
curl -sS -X POST "http://localhost:8080/api/open/apps" ^
  -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  -H "Content-Type: application/json" ^
  -d "{\"app_name\":\"测试应用\",\"description\":\"应用描述\",\"login_mode\":1,\"billing_mode\":1}"
```

## 成功响应

```json
{
  "code": 0,
  "data": {
    "app_code": "2604-AB12CD34"
  }
}
```
