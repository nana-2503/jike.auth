# 查询用户列表

## 基本信息

- 路径: `GET /api/open/users`
- 需要权限: `users:list`

## 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| app_code | string | 是 | 应用编码 |
| status | int | 否 | 按状态筛选（1:正常 2:封停 3:冻结） |
| keyword | string | 否 | 按用户名/QQ/手机/邮箱模糊搜索 |
| page | int | 否 | 页码，默认 1；小于 1 时按 1 处理 |
| size | int | 否 | 每页数量，默认 20，**最大 100**；小于 1 时按 20 处理 |

## 请求示例

```bash
curl -sS -H "X-Api-Key: osk_xxxxxxxxxxxxxxxx" ^
  "http://localhost:8080/api/open/users?app_code=2604-AB12CD34&status=1&keyword=test&page=1&size=20"
```

## 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 用户ID |
| app_code | string | 所属应用编码 |
| app_name | string | 所属应用名称 |
| username | string | 用户名 |
| status | int | 状态（1:正常 2:封停 3:冻结） |
| is_paid | int | 是否付费（0:否 1:是） |
| is_tester | int | 是否内测（0:否 1:是） |
| expire_at | string | 到期时间 |
| points | int | 点数余额 |
| channels | int | 通道数 |
| features | int | 特征数 |
| qq | string | QQ号 |
| phone | string | 手机号 |
| email | string | 邮箱 |
| cloud_data | string | 云端数据（与客户端同步的云端存储内容） |
| created_at | string | 注册时间 |
